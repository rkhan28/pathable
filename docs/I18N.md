# Internationalization

- **Library:** next-intl 4. The locale is read with `next/root-params` (Cache
  Components), and routing is handled by `src/proxy.ts`.
- **Registry:** 12 languages in `src/i18n/locales.ts`, each with its endonym and
  direction.
  - en-CA and fr-CA are shipped.
  - es, ar, zh-Hans, zh-Hant, hi, ur, bn, pa, ta and pt are listed as
    "Coming later". They are enabled only after a fluent reviewer signs off on a
    full translation.
- **Right to left:** Arabic and Urdu are registered as right to left. Layout
  uses logical CSS properties throughout, and direction-dependent icons flip.
  RTL has not been visually verified yet, because neither language is enabled.
- **Canadian French:** "bateau de trottoir" for curb ramp, "marchette" for
  walker, "triporteur ou quadriporteur" for mobility scooter, and "Nous
  joindre" for Contact.
- **Tests** (`src/i18n/i18n.test.ts`):
  - key parity;
  - placeholder parity;
  - every message compiles as ICU;
  - French is not a copy of English, apart from a reviewed list of cognates;
  - the enabled list matches the registry and the router.
- **Long-form pages** (`src/content/`) have their own structure-parity test.
- **Language switching** keeps the page, the query, the trip and the selected
  route. This is covered by an e2e test, which caught a rehydration bug.
